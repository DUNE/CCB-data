D. ESTIMATE vs ACTUAL — KEY COMPARISON
======================================================================

  Expected (Table 1 rates × actual POT):     4,920 GPU node hrs
  Measured (m3249 prod, Nov–Jan):            17,271 GPU node hrs
  Measured (m3249 prod, Aug–Jan):            18,639 GPU node hrs

  Ratio (Nov–Jan):  17,271 / 4,920 = 3.51×
  Ratio (Aug–Jan):  18,639 / 4,920 = 3.79×

  The benchmark-based estimate underpredicts by ~3.5×.

  Possible explanations for the discrepancy:
  - Benchmark was charge-only (no light) — if light sim was included
    in production, could substantially increase GPU time
  - Antifiducial reuse rate of 4 may not have been achieved
  - Failed/retried jobs that consumed GPU without producing output
  - Campaign commissioning, debugging, test productions
  - Aug–Oct usage (~1,368 NH) appears to be test campaigns
  - Additional processing steps beyond what Table 1 benchmarks cover

  OPEN: Need to confirm which of these factors apply. The benchmark
  conditions (charge-only, reuse rate 4) are explicitly stated in the
  ND Resource Projections document.
